## 0.4.4 - 2026-06-05

_Additive release — `templates.json` gains comma-separated section keys (share one stylesheet/script block across several routes at once) and an optional `_common.config` block for page-level defaults. No breaking changes, no settings reset._

### Added
* templates.json section keys may now be comma-separated (for example "products, productDetail") to share a stylesheet or script block across several routes at once. The block is replicated under each named section, merging into any section you also declare on its own, so a section's own keys win on collision.
* templates.json now accepts an optional `_common.config` block for page-level defaults (such as routeNameAsFilenameEnabled or javascriptsDeferEnabled). It is flattened back into _common at load time, so existing bundles are unaffected and any direct _common key still overrides the config block.
