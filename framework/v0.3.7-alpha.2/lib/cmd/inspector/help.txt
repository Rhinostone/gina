
  Usage: gina inspector:<action> [options]

  Actions:

    open [bundle] [@project]    Open the Inspector SPA in a chromeless browser window

  Options:

    --browser=<name>            Override the default browser
                                Available: chrome, chromium, edge, brave,
                                           vivaldi, opera, firefox, safari

    --port=<number>             Override the bundle port (skip config lookup)

    --url=<url>                 Override the Inspector base URL (standalone
                                SPA). Takes precedence over the bundle's
                                `settings.inspector.url`. The final URL
                                opened is `<url>?target=<target-origin>`.

  Inspector URL resolution order:

    1. --url=<url>                             (explicit override)
    2. Bundle config/settings.json > inspector.url
       e.g. "inspector": {"url": "http://localhost:4200/inspector/"}
    3. Embedded popup at <target>/_gina/inspector/  (legacy fallback)

  Examples:

    gina inspector:open                         Open for default bundle on port 3100
    gina inspector:open demo @myproject         Open for bundle "demo" (uses settings.inspector.url if set, else embedded)
    gina inspector:open --port=3200             Open for a specific port (embedded)
    gina inspector:open --browser=chrome        Force Chrome (app mode)
    gina inspector:open --browser=firefox       Force Firefox (normal window)
    gina inspector:open --url=http://localhost:4200/inspector/ --port=3200
                                                Force the standalone Inspector SPA at the given URL

  App mode support (chromeless window — no address bar, no tabs):

    Supported:    chrome, chromium, edge, brave, vivaldi, opera
    Not supported: firefox, safari (opens in a normal browser window)
